Machine Payments Protocol (MPP) を使用すると、自律型エージェントはアカウントの事前登録や API キーの保存を行うことなく、HTTP `402 Payment Required` を介して一部の読み取り専用 XRoute データ API リクエストに対して直接支払うことができます。

## 有料リクエストの仕組み

1. **初回リクエスト:** エージェントは `Authorization` ヘッダーなしで、対象のデータエンドポイントを呼び出します。
2. **402 オファー:** XRoute は `HTTP 402 Payment Required` と、正確な USD マイクロプライスおよび決済手順を含む MPP 支払いオファーヘッダーを返します。
3. **決済と再試行:** エージェントのウォレットが支払い証明に署名し、`X-Payment-Proof` ヘッダーを付与してリクエストを再試行します。
4. **提供:** XRoute は決済を検証し、リアルタイムデータのペイロードを即座に返します。

## エージェント向けの安全ルール

- 支払い証明に署名する前に、`402` オファーの金額がタスクの 1 回の呼び出しあたりの上限予算内であることを必ず確認してください。
- 高頻度のワークフローを実行する場合は、標準のプリペイドクレジット（`Authorization: Bearer $XROUTE_API_KEY`）または MCP OAuth の使用を推奨します。

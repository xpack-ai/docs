## エンドポイント

`GET https://api.xroute.ai/v1/models`

このエンドポイントは**無料**で利用でき、60 以上のテキスト、推論、画像、動画、および音声モデルの最新カタログを返します。

```bash
curl https://api.xroute.ai/v1/models \
  -H "Authorization: Bearer $XROUTE_API_KEY"
```

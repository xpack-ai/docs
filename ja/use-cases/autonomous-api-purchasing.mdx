## 課題

自律型エージェントは有料ツールを動的に呼び出す必要がありますが、無制限の API アクセスを許可すると予期しない費用が発生するリスクがあります。

## ワークフローアーキテクチャ

1. **無料ディスカバリ:** エージェントは `https://mcp.xroute.ai/mcp` 上で `search` と `get_details` を無料で実行します。
2. **一括見積もり:** エージェントは予定している操作を指定して `batch_quote` を呼び出し、正確な単価と `auto_execute_eligible` を受け取ります。
3. **予算ゲート:**
   - 合計コストがキーの自動実行上限未満の場合、エージェントは即座に処理を続行します。
   - それ以外の場合、エージェントは一時停止し、ユーザーに正確な USD 予算の承認を求めます。
4. **実行と決済:** エージェントは `execute` を実行（または HTTP 402 MPP 経由で決済）し、確定したコストを記録します。

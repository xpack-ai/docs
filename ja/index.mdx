XRoute は、AI エージェントと開発者がテキスト・画像・動画の各モデルを検索、呼び出し、決済するための単一のゲートウェイを提供します。

ベンダーごとに個別のアカウントやサブスクリプションを管理する代わりに、1 つの API キーで以下にアクセスできます。

- **主要な LLM とマルチモーダルモデル:** OpenAI 形式、Anthropic 形式、またはネイティブ形式を通じて、OpenAI、Anthropic、Gemini、Grok、DeepSeek、Byteplus Ark、Qwen、Kimi、GLM、MiniMax などを呼び出せます。
- **画像・動画生成モデル:** OpenAI DALL-E、火山方舟 Seedream、Google Imagen、Seedance 動画、および阿里 WAN 動画生成モデルをネイティブ呼び出しできます。
- **従量課金:** すべての呼び出しは単一のプリペイド残高から引き落とされ、キーごとの利用上限設定や透明性の高いトークン・使用量コスト計算をサポートします。

## AI エージェント向け

XRoute をツールとしてエージェントに接続します。サインインはブラウザの OAuth 経由で行われるため、API キーをコピーする必要はありません。

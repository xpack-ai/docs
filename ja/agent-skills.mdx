</Info>

XRoute Agent Skills は、Claude Code、Codex、Cursor、およびカスタムエージェント向けに、マルチモデルルーティング、ディープ Web 検索、金融市場分析、マルチモーダルメディア生成を網羅したポータブルな指示バンドルを提供します。

## 今すぐエージェントを接続する

Agent Skills の公開準備が進められている間も、OpenAI 互換 SDK またはカスタム Base URL の上書き設定を通じてエージェントを直接接続できます。

**Voucher（バウチャー）画面**（`https://xroute.ai/personal/credit`）では、キャンペーンやパートナーシップ等で取得したバウチャー資産を管理できます。

  <img src="/images/console/voucher.png" alt="バウチャー管理" />
</Frame>

## 優先控除ルール

XRoute のモデルや API を呼び出す際：

<Tip>
**バウチャーは常に現金アカウント残高より優先して消費されます。**

利用対象リソースに一致する有効なバウチャーがある場合、システムは自動的にバウチャー残高から優先的に相殺し、バウチャーが尽きた後にのみ現金残高が引き落とされます。
</Tip>

---

## バウチャーの引き換え

プロモーションコードやギフトカードをお持ちの場合：

1. **Voucher Redemption** エリアで **Redeem** をクリックします。
2. 入力欄に **Voucher Code** を入力します。
3. 確定すると、バウチャーの額面が即座にアカウントに反映されます。

---

## バウチャー資産一覧

資産テーブルで各バウチャーの有効性やステータスを確認できます：

| 項目 | 説明 |
| :--- | :--- |
| **Voucher ID** | システム内部の一意な識別コード。 |
| **Voucher Name** | キャンペーンやクーポンの名称（例：新規開発者ウェルカムクレジット）。 |
| **Face Value** | 引き換え時の初期額面（USD）。 |
| **Balance** | 現在利用可能な残額。 |
| **Usage Scope** | 適用可能なモデル・サービス範囲（例：全モデル、テキストモデル限定など）。 |
| **Redemption Time** | 引き換えが完了した日時。 |
| **Validity Period** | 有効期限。期限が切れると未消費分は失効します。 |
| **Status** | 現在の状態（有効、使い切り、期限切れ）。 |
| **Actions** | 控除履歴や規約の確認。 |

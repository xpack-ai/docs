**Account Balance（アカウント残高）画面**（`https://xroute.ai/personal/balance`）では、前払い残高、オンラインチャージ履歴、リソース別支出状況を一元管理できます。

## 現在のアカウント残高

上部カードに **Current Account Balance (USD)（現在の残高）** が表示されます：

- モデルや API 呼び出しに利用可能な現金残高をリアルタイム表示。
- **Recharge Now（今すぐチャージ）**：安全な決済ウィンドウを開き、オンラインで即時チャージできます。
- **Check Legacy System Balance**：旧 XRoute システムの残高がある場合に確認・移行できます。

---

## 消費履歴とチャージ記録

残高カードの下に、2つの主要な履歴タブがあります：

### 1. 日次消費記録（Daily Consumption Records）
日ごとに集計された利用データ：
- **請求日**
- **呼び出し回数**
- **トークン消費量**
- **バウチャー相殺額**
- **現金残高控除額**

### 2. チャージ記録（Recharge Records）
監査可能な支払い履歴：
- **注文 ID**
- **チャージ金額（USD）**
- **決済チャネル・手段**
- **注文作成日時および決済完了日時**
- **ステータス**（決済完了、処理中、返金済みなど）

---

## 子リソース消費明細（TOP 20）

支出の主要因を迅速に特定するため、選択期間内に**消費額の高かった上位 20 リソース**を自動分析・ランキング表示します：

| カラム | 説明 |
| :--- | :--- |
| **Ranking** | 消費額の降順ランキング（1〜20位）。 |
| **Child Resource Name** | 具体的なモデル名（例：`Anthropic/claude-fable-5`、`OpenAI/gpt-6-astra`）。 |
| **Parent Resource Name** | プロバイダー名または親グループ。 |
| **Resource Type** | 生成モダリティ（`text` テキスト、`image` 画像、`video` 動画）。 |
| **Invocations** | そのモデルに対する総呼び出しリクエスト数。 |
| **Last Call Time** | 最後に呼び出された日時。 |
| **Consumption Amount (USD)** | そのリソースによって発生した総消費金額。 |

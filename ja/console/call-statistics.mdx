**Call Statistics（呼び出し統計）画面**（`https://xroute.ai/personal/call`）は、XRoute を経由する全 API トラフィックのリアルタイム運用分析とエンドツーエンドの監査性を提供します。

## 期間と高度なフィルター

画面上部で分析対象の期間や絞り込みを設定できます：

- **クイックプリセット**：**Today（本日）**、**Yesterday（昨日）**、**Last 7 Days（過去7日間）**、または **Custom Period（カスタム期間）**。
- **Personal Rate Limits and Quotas**：現在のアカウントの QPM（1分あたりリクエスト数上限）や並行処理上限の確認。
- **Advanced Filter（高度なフィルター）**：特定の **プロバイダー**、**モデル**、**ステータスコード**（例：200、429、500）、または **認証キー** で絞り込み。

---

## 主要指標タイル

5つの重要指標カードで全体の稼働健全性を素早く把握できます：

- **Total Calls（総呼び出し回数）**：選択期間内に処理された全 API リクエストの総数。
- **Success Call Rate（成功率）**：HTTP 200 で正常終了したリクエストの割合。
- **Average Duration（平均所要時間）**：エンドツーエンドの応答レイテンシ（ミリ秒または秒）。
- **Total Tokens Called（総呼び出しトークン数）**：入力（Prompt）と出力（Completion）を合算したトークン総量。
- **Total Consumption Amount（総消費金額）**：対象期間内に精算された純コスト（USD）。

---

## モデル別呼び出し推移（Model Invocation Trend）

インタラクティブな折れ線・エリアチャートでトラフィックの推移を可視化します：
- 日ごとのトラフィック変動の比較。
- 各モデル・プロバイダーごとの利用比率（例：Anthropic vs OpenAI vs DeepSeek）の把握。

---

## リクエスト別監査ログ（Recent Invocations）

テーブルには、1リクエストごとの詳細なトランザクションが記録されます：

| 項目 | 説明 |
| :--- | :--- |
| **Request Time** | リクエストがゲートウェイに到達した正確な時刻。 |
| **Provider & Model** | 実際に処理を実行したプロバイダーとモデル。 |
| **Duration** | 上流処理とゲートウェイ転送を含む総レイテンシ。 |
| **Status** | HTTP ステータスコード。 |
| **Consumer & Key** | 呼び出しを行った認証キー識別子。 |
| **Token 内訳** | **INPUT**、**OUTPUT**、**TOTAL** トークンの正確なカウント。 |
| **課金・控除** | 適用単価、割引単価、バウチャー控除額、現金残高引き落とし額。 |

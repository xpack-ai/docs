**XRoute コンソール**（`https://xroute.ai/personal/dashboard`）は、AI ゲートウェイアカウント、API 認証情報、モデルルーティングポリシー、請求アセット、トラフィック監視を一元管理するメインコントロールパネルです。

## 機能構成とモジュール一覧

コンソールは左側のサイドバーで大きく2つのセクションに分かれています：

### 1. 個人アカウント管理（PERSONAL ACCOUNT）

| 機能モジュール | ルート | 概要 |
| :--- | :--- | :--- |
| **[ダッシュボード](/ja/console/dashboard)** | `/personal/dashboard` | 残高、本日の利用額、クイック呼び出しコード、直近のリクエスト詳細をリアルタイム表示。 |
| **[お知らせ・通知](/ja/console/notifications)** | `/personal/todo` | 販売代理店申請のフィードバックやシステムメンテナンス通知を受信するインサイト通知センター。 |
| **[アクセス認証情報](/ja/console/credentials)** | `/personal/keys` | アプリケーション用 API キー（`sk-...`）の作成、コピー、アクセススコープ管理。 |
| **[アカウント残高](/ja/console/balance)** | `/personal/balance` | オンライン即時チャージ、日次利用推移、消費額 TOP 20 リソースランキング。 |
| **[バウチャー（クーポン）](/ja/console/voucher)** | `/personal/credit` | バウチャーコードの適用、現金残高に優先して相殺される有効クーポンの管理。 |
| **[利用可能リソース](/ja/console/resources)** | `/personal/resources` | アカウントおよび参加中のリソースグループに認可されている全モデルとプロバイダーの一覧。 |
| **[モデルマッピングポリシー](/ja/console/model-mapping)** | `/personal/model-mapping` | リクエストエイリアス、パラメータテンプレート、マルチプロバイダー自動フェイルオーバー設定。 |

### 2. レポート（REPORTS）

| 機能モジュール | ルート | 概要 |
| :--- | :--- | :--- |
| **[呼び出し統計](/ja/console/call-statistics)** | `/personal/call` | 多次元トラフィック分析：呼び出し回数、成功率、レイテンシ、トークン量、利用金額、詳細監査ログ。 |

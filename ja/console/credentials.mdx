**Access Credentials（アクセス認証情報）画面**（`https://xroute.ai/personal/keys`）では、アプリケーション、バックエンド、AI エージェントが XRoute に接続するための API キーを管理します。

</Frame>

## デフォルトキー（default）

アカウント登録時に、XRoute は自動的に **`default`** という名前のプライマリ認証情報を発行します：

- **キー形式**：`sk-` で始まる暗号化された 16 進数トークン。
- **リソース権限**：デフォルトでは**アカウント権限に動的追従**し、アカウントおよび参加リソースグループに認可されたすべてのモデルに自動アクセスできます。
- **基本操作**：
  - 目のアイコンをクリックしてキーを表示、コピーボタンでクリップボードにコピーできます。
  - 作成日時や関連付けられたリソースグループを確認できます。

---

## 新しい API キーの作成

本番環境、ステージング環境、または異なるアプリケーションごとにキーを分離する場合：

1. 認証情報カード右上の **Create** ボタンをクリックします。
2. モーダルで識別しやすい **Credential Name**（例：`claude-code-cli`、`cursor-ide`、`prod-backend`）を入力します。
3. リソース権限スコープを設定します：
   - **動的追従**：アカウントが所有する全モデルへのアクセス権を自動継承します。
   - **カスタムスコープ**：特定のリソースグループやモデルに限定します。
4. **Confirm** をクリックして新しい API キーを発行します。

<Warning>
`sk-...` 形式の API キーは機密情報です。パブリックなリポジトリにコミットしたり、ブラウザ側のコードに露出させないようご注意ください。
</Warning>

以下のステップに従って XRoute API キーを作成し、最先端の LLM およびマルチモーダル生成 API を呼び出して、利用状況を確認します。

<Tip>
本ガイドは、**クイックスタート · 開発者向け** グループの統一ドキュメント [クイックスタート：APIキーの取得と初回呼び出し](/ja/quickstart) に統合されました。
</Tip>

## 1. アカウントとキーを作成する

1. [xroute.ai/en](https://xroute.ai/en) にサインインし、**Get API Access** またはユーザーアバターをクリックしてコンソールを開きます。
2. 左側メニューで **Access Credentials (アクセス資格情報)**（`https://xroute.ai/personal/keys`）に移動します。
3. `default` キーまたは作成したキーの API Key 入力欄の右側にある **コピー** アイコンをクリックして、シークレットキー（`sk-...`）をコピーします。

<Frame caption="XRoute Access Credentials コンソール画面と API Key のコピー">
  <img src="/images/quickstart/api-keys-overview.png" alt="XRoute Access Credentials" />
</Frame>

4. （任意）サービスごとに個別のキーを割り当てる場合は、リスト上部の **+ Create** をクリックして新しいキーを作成します。

<Frame caption="新規アクセス資格情報作成ダイアログ">
  <img src="/images/quickstart/create-api-key-modal.png" alt="新規アクセス資格情報作成" />
</Frame>

5. シェル環境にキーをエクスポートします：

```bash
export XROUTE_API_KEY="xr_live_your_key_here"
```

<Warning>
`$XROUTE_API_KEY` を公開 Git リポジトリにコミットしたり、信頼できないログに出力したりしないでください。
</Warning>

---

## 2. 最初のモデル呼び出しを実行する

XRoute はテキスト、画像、動画などの多様な生成タイプをサポートしています。出力タイプに応じて適切なエンドポイントとプロトコルを選択してください：

<Note>
- **テキスト出力モデル（Text）**: **OpenAI 統合形式**、**Anthropic 統合形式**、および**プロバイダーネイティブ形式**をサポートします。
- **画像出力モデル（Image）**: **プロバイダーネイティブ形式のみ**をサポートします（例: OpenAI Images API または Byteplus Images API）。
- **動画出力モデル（Video）**: **ネイティブ非同期タスク形式のみ**をサポートします（タスクを送信して生成し、ステータスをポーリング）。
</Note>

<Tip>
**最速の実行方法**：個人コンソールの **Dashboard**（`https://xroute.ai/personal/dashboard`）にある **Quick Call Guide** を使用してモデルと認証情報を選択し、**Copy Code** をクリックすれば、API Key が埋め込まれた cURL コマンドをコピーしてすぐに実行できます。
</Tip>

### A. テキスト生成（OpenAI 統合形式）

`https://api.xroute.ai/v1/chat/completions` にリクエストを送信します：

```bash
curl -X POST "https://api.xroute.ai/v1/chat/completions" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "OpenAI/gpt-5.6-sol",
    "messages": [
      {"role": "system", "content": "You are a concise technical assistant."},
      {"role": "user", "content": "Explain low-latency edge routing in 3 bullet points."}
    ]
  }'
```

### B. テキスト生成（Anthropic 統合形式）

`https://api.xroute.ai/v1/messages` にリクエストを送信します：

```bash
curl -X POST "https://api.xroute.ai/v1/messages" \
  -H "x-api-key: $XROUTE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Anthropic/claude-fable-5",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "What makes a reliable API gateway?"}
    ]
  }'
```

### C. 画像生成（ネイティブ形式）

画像生成は Chat Completions エンドポイントを使用しません。プロバイダー専用のネイティブ画像インターフェース（例: OpenAI 形式）を直接呼び出します：

```bash
curl -X POST "https://api.xroute.ai/OpenAI/images/generations" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "An ultra-modern data center glowing in cyberpunk neon lights, 8k resolution",
    "size": "1024x1024"
  }'
```

### D. 動画生成（ネイティブ非同期タスク）

動画生成は非同期ワークフローを採用しています：まず生成タスクを送信し、タスク ID でステータスをポーリングします（例: Byteplus）：

```bash
# 1. 動画生成タスクを送信
curl -X POST "https://api.xroute.ai/Byteplus/contents/generations/tasks" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-1-5-pro-251215",
    "content": [
      {"type": "text", "text": "A drone flying through a sunset canyon, cinematic lighting"}
    ]
  }'

# 2. 返却された task id で進捗と結果を照会
# curl -X GET "https://api.xroute.ai/Byteplus/contents/generations/tasks/{task_id}" \
#   -H "Authorization: Bearer $XROUTE_API_KEY"
```

## 3. 利用金額の確認とトラフィック監視

利用状況、残り残高、モデルの呼び出しトラフィックは Web コンソール上で直接追跡できます：

- **Dashboard**: [Personal Dashboard](https://xroute.ai/personal/dashboard) を開き、リアルタイムの **Account Balance (アカウント残高)** と **Today's Usage (当日の利用額)** を確認できます。
- **Call Statistics**: 左側メニューの **REPORTS** 配下にある [Call Statistics](https://xroute.ai/personal/call) を開き、**Total Calls (総呼び出し数)**、**Success Call Rate (成功率)**、**Average Duration (平均所要時間)**、**Total Tokens Called (消費トークン数)**、**Total Consumption Amount (消費金額)**、およびモデル別の **Model Invocation Trend (呼び出し推移グラフ)** を詳細に把握できます。

  <img src="/images/quickstart/call-statistics.png" alt="XRoute 呼び出し統計" />

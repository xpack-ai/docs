Cursor を設定して XRoute をモデルゲートウェイとして活用し、各プロバイダーの最先端モデルを呼び出します。

## 1. Cursor で XRoute モデルを設定する（推奨）

**Cursor Settings -> Models** を開きます：

1. **Override OpenAI Base URL** を有効化し、次のように設定します：
   ```text
   https://api.xroute.ai/v1
   ```
2. OpenAI API Key 欄に `XROUTE_API_KEY` を貼り付けます。
3. 利用したいモデル ID を追加します（例）：
   - `OpenAI/gpt-5.6-sol`
   - `Deepseek/deepseek-v4-flash`
   - `Anthropic/claude-fable-5`
   - `Google/gemini-3.1-pro-preview`

## 2. リモート MCP サーバー（近日公開）

<Info>
XRoute リモート MCP サーバーは現在開発中です。公開後は `.cursor/mcp.json` から簡単に接続可能になります：
</Info>

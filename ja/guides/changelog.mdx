## v1.7

> **Agent 読み取り・呼び出し対応 & クーポンシステム**

### Agent 呼び出し対応、クーポンシステム、課金計算式の透明化

- **Agent 読み取り・呼び出しサポート：** AI Agent によるリソース探索・読み取り・API 呼び出し体験を全面最適化しました。
- **おすすめリソース設定：** システムおよびチャネル管理画面の「プラットフォーム装飾」に **おすすめリソース** 設定を追加。**モデル、API、MCP** ごとに公開済みリソースを選択・並び替えでき、フロント画面一覧の先頭に最大 8 件を優先表示します。
- **クーポン（代金券）システム：**
  - **クーポン作成・管理：** 財務管理に **クーポン管理** を追加。6〜18 文字の英数字コード（カスタムまたは自動生成）、額面（チャネル残高から事前控除）、有効期限（最長 1 年）、利用可能回数、適用範囲（全サイトまたは特定のモデル／API 親子リソース）を設定可能。
  - **個人引き換え＆独立ページ（`/redeem`）：** 個人コンソールの「アカウント残高」配下に **クーポン** メニューを追加し、キャンペーン配布用の独立引き換えページ（`/redeem` およびフッターリンク）を公開。複数クーポン適用時は有効期限が近いものから優先消化し、不足分はアカウント残高から自動控除されます。
- **消費金額アルゴリズムと控除明細の表示：** 呼び出し統計一覧に表示列カスタマイズ機能を追加し、**標準価格、割引後価格、単位（`M token` / `call` / `s`）、課金計算式（実際の変数を代入表示）、消費金額、クーポン控除額、残高控除額** カラムを追加しました。
- **カスタムメニュー URL パス＆トップバナーリンク：** HTML アップロード形式のカスタムメニューで専用パス（`/pages/{custom_path}`）の指定と重複チェックに対応。トップ広告バナーに新規タブ遷移用のリンク URL 設定を追加しました。

## v1.6

> **取引課金とサブスクリプション審査の併用**

### 取引・サブスクリプション併用モード、プラットフォーム装飾、モデルエイリアスマッピング

- **取引課金とサブスクリプション審査の併用：** システム設定に **機能設定** を追加。従来の「サブスクリプションモード」「課金モード」の択一制限を撤廃し、**未認可リソースの表示、サブスクリプション申請・審査、有料取引、販売チャネル** および有効化するリソース種別（AI モデル / API サービス / MCP）を個別に ON/OFF 可能にしました。
- **プラットフォーム装飾＆多言語ナビゲーション：** システム・チャネル管理画面に **プラットフォーム装飾** を追加。多言語（中・英など）でトップメニュー名をカスタマイズし、公式ページ（ホーム、モデル、API、MCP）、外部リンク、またはローカル HTML ファイルへ紐付け可能になりました。
- **コンシューマーモデルエイリアスマッピング＆ユーザーレベル障害切り替え：** 個人コンソールとリソースグループ詳細に **モデルエイリアスマッピング** を追加。任意のエイリアス名を指定プロバイダーモデルにマッピングし、優先度順のフォールバックモデル（プラットフォーム全体のフェイルオーバーより優先され、実際に呼び出されたモデル料金で課金）を設定できます。
- **多彩なチャージ方式：** アカウント管理に **新規登録ユーザーへの自動ボーナス付与** スイッチと **一括チャージ**（全選択、リソースグループ指定、複数ユーザー選択、および履歴ログ記録）を追加しました。
- **通知・お知らせセンターへの刷新：** 従来の「ToDo 通知」を **通知・お知らせ** に刷新し、個人向けシステム通知（販売チャネル申請の審査結果・却下理由）とチャネル向け系统通知（上流モデルの公開／停止・価格変更アラート）を追加しました。

## v1.5

> **マルチモーダルオンラインデバッグ & 二次チャネル画面最適化**

### マルチモーダル Playground と二次チャネル向け動的ブランディング

- **マルチモーダルオンラインデバッグ（Playground）：**
  - モデル詳細ページに **オンライン体験** タブを追加。複数のリクエスト URL 形式の切り替えと、**動的フォーム**・**JSON エディタ** 間の双方向リアルタイム同期に対応しました。
  - **テキスト（Text）、画像（Image）、動画（Video）** モデルのオンラインデバッグに対応（動画モデルでは非同期タスク生成とタスク ID による結果プレビューをサポート）。複数画像・動画のサムネイル切り替えやプレビュー／JSON 応答の切り替えが可能です。
- **二次チャネル向けフロント全画面の動的ブランディング：**
  - チャネル独自のロゴ、ブランド名、トップページコピー、モデル一覧（モデル数 0 のカテゴリを自動非表示）、モデルライブラリスローガンを全画面で動的反映。
  - **トップ広告バー設定**（文言、文字色、グラデーション背景カラーピッカー）、**連絡先設定**（X、メールなど）、および下流チャネル向けの **プライバシーポリシー・利用規約のドメイン／法人名／連絡先メール自動置換** に対応しました。
- **チャネル管理「クイックスタート」ガイド：** チャネル管理画面の左メニューに 4 ステップの初期設定ガイド（**ブランド情報定義 → 公開リソース有効化 → 価格戦略設定 → チャネル残高チャージ**）を追加しました。

## v1.4

> **プロバイダー障害対策、チャージレポート、消費レポート**

### プロバイダー高可用性フェイルオーバーと請求統計レポート

- **プロバイダー障害対策（フェイルオーバー）＆キー・プールローテーション：**
  - システム管理のポリシー管理に **プロバイダー障害対策** を追加。**プロバイダーパラメータの直接置換** または **条件トリガー切り替え**（上流接続／認証／5XX／クォータ不足エラー、またはカスタム応答タイムアウト秒数超過時）を設定可能。
  - 最大 10 件のバックアッププロバイダー登録、ワンクリック疎通テスト、同一エンドポイント＋複数 API キーによる **アカウントプールローテーション** に対応しました。
- **請求統計（消費レポート＆チャージレポート）：**
  - 財務管理に **請求統計** を追加。アカウント・リソースグループ・チャネル別の **消費レポート**（上位 20 サブリソース明細へのドリルダウン対応）と **チャージレポート** を提供します。
- **個人消費明细＆アカウント残高ドリルダウン：** 個人コンソール「アカウント残高」に上位 20 サブリソース消費ランキングを追加。アカウント管理の残高クリックで日別消費集計とチャージ履歴をポップアップ表示できるようになりました。

## v1.3

> **ダッシュボード、Claude 形式統一、ライセンス証明書**

### ロール別ダッシュボード、Claude 形式統一対応、ライセンス証明書管理

- **ロール別ダッシュボード（Dashboard）：**
  - **個人ダッシュボード：** 残高と直近 30 日間の日次消費チャート、本日の呼び出し数（前日同期比）と直近 7 日間のモデル／API 呼び出し比較グラフ、利用可能リソース集計、クイック呼び出し設定、最新 10 件の呼び出しログを集約。
  - **チャネル＆システム管理ダッシュボード：** チャネルブランド・ドメイン、今月の売上高・利益（前月比）、直近 7 日間のアクティブユーザー、下流チャネル網サマリー、リソース・組織棚卸し（本日の API 呼び出し Top 3、モデル Token 消費 Top 3）、今月のチャージ／消費 Top 5 ランキングを表示。
- **Claude フォーマット統一対応：** Anthropic Claude（`/v1/messages`）標準フォーマット呼び出しを統合サポートしました。
- **ライセンス証明書管理：** システム設定に **ライセンス証明書** メニューを追加。認可先企業、ノード数上限、許可される販売階層（0〜5 階層）、有効期限を表示し、**期限切れ・ノード数超過・販売階層超過** のリアルタイム警告バナーを提供します。

## v1.2

> **統計レポート & ポリシー管理**

### レート制限・クォータ制限ポリシー、多次元 Token 統計、売上レポート

- **レート制限＆クォータ制限ポリシー：**
  - **レート制限（Rate Limit）：** 分・時間・日・月・年・累計単位で呼び出し回数を制限。個人アカウント、リソースグループ自身のキー、メンバーキー、またはチャネル全体に適用し、消化進捗を確認可能。
  - **クォータ制限（Quota Limit）：** **100 万 Token** または **米ドル（USD）** 単位で日次・月次・年次・累計の上限を設定し、周期到来時に自動リセット。
- **呼び出し統計オーバービュー：** 総呼び出し回数（日平均含む）、平均応答時間（ms）、平均成功率、ピーク RPM、およびモデル・API・リソースグループ・アカウントの各 Top 5 ランキングを追加しました。
- **多次元 Token 統計センター：** **概要、アカウント、リソースグループ、下流チャネル、モデル** の 5 軸で累計 Token（Input / Output 内訳）、ピーク TPM、平均呼び出し消費量、平均コンシューマー消費量を可視化し、双方向ドリルダウンに対応しました。
- **売上レポート＆下流チャネル実績ドリルダウン：** 財務管理に **売上レポート** を追加。総売上高、純利益、直販額、下流販売額の推移と上位 20 リソース明細・日次売上明細（Excel エクスポート対応）を提供し、下流チャネルの売上レポートへのワンクリック遷移に対応しました。

## v1.1

> **取引システム & 多段階販売チャネル**

### 課金取引システム、多段階チャネル販売、ダイナミックプライシングエンジン

- **チャネル＆リソースグループ体系への刷新：** 従来の「テナント」を **チャネル（Channel）**、「チーム」を **リソースグループ（Resource Group）** に刷新し、多段階のリセラー販売アーキテクチャを構築しました。
- **多段階販売チャネル管理：** 個人コンソールからの **販売チャネル申請** と上流審査ワークフロー、チャネル管理者割り当て、下流チャネルの顧客数・月間実績確認、チャネル凍結／解除、独自ブランド・ロゴ・サブドメイン／独自ドメイン設定に対応しました。
- **モデル＆API サービスのきめ細かな価格設定：**
  - **モデル価格設定：** Token 単位（Input / Output）、呼び出し回数単位（Per Call）、秒単位（Per Second）、および **高度な階層型課金（Advanced Billing：キャッシュ Token、マルチモーダル入力、解像度別動画秒単価など）** に対応。**公式価格（取消線表示）、仕入価格、販売価格** の 3 ビューと比率ベースの **動的価格調整ポリシー**（赤字防止の仕入価格下限保護付き）を提供します。
  - **API サービス価格設定：** 呼び出し単位（Per Call）のデフォルト価格およびエンドポイント別価格ルールに対応。
- **リソースグループ割引ポリシー：** 特定のリソースグループに対してモデルや API エンドポイントごとの割引率を設定できるバージョン管理付き **割引ポリシー** を追加しました。
- **アカウントチャージ、チャネル配分、利益分配（精算）：**
  - 米ドル残高管理（小数点以下 6 桁）、Stripe オンラインチャージ、チャネル管理者によるオフライン残高配分、システム管理画面での充当・控除に対応。
  - **販売利益分配** 機能を追加し、出金最低額（デフォルト $100）・手数料率（デフォルト 2%）設定、受取銀行口座登録、精算期間ごとの出金申請・上流承認・振込確認ワークフローを実装しました。
- **モデル＆API 呼び出し統計：** 入出力 Token、拡張課金パラメータ、クライアント IP、リクエスト／レスポンス本文、消費金額を記録する統計ダッシュボードと監査ログを追加しました。

## v1.0

> **UI フレームワークと基本ロジックの再構築**

### Model・API・MCP を統合した AI リソースオープンプラットフォーム基盘

- **3 大 AI リソース統合ポータル：** フロント画面のホームおよびナビゲーションを刷新し、**AI モデル（Model）、API インターフェース（API）、MCP サービス（MCP）** のカテゴリ検索と統合呼び出しガイドを一元化。サイト名・ロゴ・メインコピーのカスタマイズに対応しました。
- **統合呼び出し＆ネイティブ呼び出しのデュアルモード：**
  - **モデル詳細ページ：** **統合呼び出しモード**（OpenAI 互換エンドポイント）と **ネイティブ呼び出しモード**（上流ネイティブパスおよび `text_to_video`、`image_to_video` などのサブパス）を追加し、選択したチーム・API キーのサンプルコード自動埋め込みに対応しました。
  - **API / MCP 詳細ページ：** Overview、API 一覧、MCP Tools タブを統合し、インタラクティブな API デバッグパネルと多言語コードサンプル（cURL、Python、Java、PHP など）のワンクリックコピーを提供。
- **2 階層権限モデルへの簡素化：** 従来の「チーム → コンシューマー → 認証キー」の 3 階層からコンシューマー階層を廃止し、**「チーム（リソースグループ）→ 認証キー」** の 2 階層に簡素化。チーム／アカウント権限の動的継承と、キー単位での個別リソース認可の双方に対応しました。
- **バージョン公開管理＆即時呼び出しスイッチ：** API サービスおよびモデルプロバイダーのバージョン公開管理と初回公開チェックリストを導入。再公開なしで即座に反映されるプロバイダー／モデル単位の **呼び出し状態スイッチ** を追加しました。
- **統合 ToDo 通知＆チームコラボレーション：** サブスクリプション認可申請を一元審査する **ToDo 通知** センター、招待リンクによるチーム参加、新規アカウントへのデフォルトリソースグループ割り当て設定を追加しました。

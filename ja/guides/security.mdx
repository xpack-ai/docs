XRoute は、厳格なデータプライバシーと予測可能なエージェントガバナンスのために設計された、エンタープライズグレードの AI ゲートウェイアーキテクチャ上に構築されています。

## データ処理

XRoute は高速なルーティングおよび決済レイヤーとして機能します。リクエストは認証され、最も健全なアップストリームクラスターにルーティングされた後、クライアントへ直接返却されます。

## プロンプトと出力の保持ポリシー

- **データを使用した学習ゼロ:** XRoute は、お客様のプロンプト、補完結果、またはデータ API のペイロードをモデルの学習に一切使用しません。
- **デフォルトでのコンテンツログ非保存:** コンソールのワークスペースでデバッグトレースを明示的に有効にしない限り、プロンプト本文やモデルのレスポンスが XRoute のデータベースに永続化されることはありません。

## 運用メタデータ

課金、レート制限、および監査ログをサポートするため、XRoute は最小限のリクエストメタデータを記録します。

- タイムスタンプとリクエスト ID
- API キー ID と組織 ID
- 対象モデルまたはエンドポイント ID
- トークン数（入力/出力）と決済された USD コスト
- HTTP ステータスコードとレイテンシ

## 認証と通信

- すべてのトラフィックには **TLS 1.2 以上**（`https://api.xroute.ai` および `https://mcp.xroute.ai`）が必要です。
- API キーはソルト付き暗号学的ハッシュとして保存されます。

## エージェントの安全管理

自律エージェントに XRoute へのアクセス権を付与する場合は、以下の対策を推奨します。

1. 平文ファイルで生の API キーを共有する代わりに、**OAuth MCP サインイン**を使用します。
2. コンソールで**キーごとの利用上限**を設定します。
3. 書き込み操作や自動実行の見積もりしきい値を超える呼び出しを実行する前に、ユーザーの確認を必須にします。

XRoute は、60 以上のすべての LLM、動画・音声生成モデル、および 100 以上のリアルタイムデータ API にわたって、共通のプリペイド Credits 残高を使用します。

## Credits とチャージ

- **1 Credit = $1.00 USD。**
- XRoute コンソールから、クレジットカード、Alipay、WeChat Pay、または暗号資産で残高をチャージできます。
- Credits はテキストモデル、推論モデル、動画生成（Seedance 2.5 など）、音声合成、およびデータ API に共通して適用されます。

## モデル

- **テキストおよび推論モデル:** 100 万入力トークンおよび 100 万出力トークンあたりで課金されます。50 社以上のアップストリームプロバイダーとの提携により、XRoute は公式の直接接続を下回る料金を実現しています。
- **動画および音声モデル:** 生成秒数、解像度ティア、またはリクエスト単位あたりで課金されます。

## データ API

- **固定の呼び出し単位料金:** ほとんどの検索、金融、およびソーシャル照会エンドポイントは、成功した呼び出しごとに固定の USD 金額を課金します。
- **従量制料金:** 一括抽出や複数レコードのエンドポイントは、予測可能な基本料金に加えて、返却されたアイテムごとに課金します。

## コスト予測、見積もり、課金

検索と見積もりは常に**無料**です。

- `GET /v1/models`
- MCP 操作: `account`、`list_categories`、`search`、`get_details`、`batch_quote`
- CLI コマンド: `xroute account`、`xroute search`、`xroute details`、`xroute quote --json`

## 見積もり・確認・実行の流れ

エージェントワークフローで有料呼び出しを実行する前に、見積もりをリクエストします。

```bash
xroute quote search/web --json
```

見積もりが `"auto_execute_eligible": true` を返した場合、その呼び出しは事前承認済みのしきい値内に収まっており、即座に実行できます。それ以外の場合、エージェントは計画された呼び出し、単価、合計 USD 予算を提示して承認を求めます。

## エージェントワークフローの予算管理

コンソールでの**キーごとの利用上限**と**呼び出し前の見積もり**（`batch_quote`）を組み合わせることで、自律ループが意図した予算を超過するのを防ぐことができます。

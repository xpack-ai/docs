XRoute ゲートウェイは、世界トップクラスの AI モデルにシームレスに接続します。プラットフォームは主に **テキスト (Text)**、**画像 (Image)**、**動画 (Video)** の 3 つの出力タイプをサポートしています。

出力タイプに応じて、厳格なプロトコル呼び出しルールが適用されます：
- **テキストモデル（Text）**：**OpenAI 統一フォーマット**、**Anthropic 統一フォーマット**、および **プロバイダーネイティブフォーマット** の 3 通りをサポート。
- **画像モデル（Image）**：**プロバイダーネイティブフォーマットのみ**（OpenAI Images API、Google Image generateContent、Byteplus Images、Qwen Multimodal API 等）。
- **動画モデル（Video）**：**プロバイダーネイティブ非同期タスク形式のみ**（タスク発行 + 完了までのポーリング、Byteplus 生成タスクや WAN DashScope 非同期タスク）。

<Tip>
ナビゲーション右上の「Models」または [XRoute モデルハブ (xroute.ai/model)](https://xroute.ai/en/model) から、最新のモデル一覧と料金体系をご確認いただけます。
</Tip>

## テキスト出力モデルの呼び出し例

テキストモデルは OpenAI 互換エンドポイント、Anthropic 互換エンドポイント、およびプロバイダーネイティブエンドポイントのいずれからも呼び出せます。

<Tabs>
  <Tab title="1. OpenAI 統一フォーマット">
    エンドポイントは `https://api.xroute.ai/v1/chat/completions` です：

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://api.xroute.ai/v1/chat/completions" \
      -H "Authorization: Bearer $XROUTE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "OpenAI/gpt-5.6-sol",
        "messages": [
          {"role": "user", "content": "9.9 と 9.11 はどちらが大きいですか？簡潔に説明してください。"}
        ],
        "temperature": 0.7
      }'
    ```

    ```python Python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://api.xroute.ai/v1",
        api_key="your_xroute_api_key",
    )

    response = client.chat.completions.create(
        model="OpenAI/gpt-5.6-sol",
        messages=[{"role": "user", "content": "9.9 と 9.11 はどちらが大きいですか？"}],
    )
    print(response.choices[0].message.content)
    ```

    ```typescript TypeScript
    import OpenAI from 'openai';

    const client = new OpenAI({
      baseURL: 'https://api.xroute.ai/v1',
      apiKey: process.env.XROUTE_API_KEY,
    });

    const completion = await client.chat.completions.create({
      model: 'OpenAI/gpt-5.6-sol',
      messages: [{ role: 'user', content: '9.9 と 9.11 はどちらが大きいですか？' }],
    });
    console.log(completion.choices[0].message.content);
    ```
    </CodeGroup>
  </Tab>

  <Tab title="2. Anthropic 統一フォーマット">
    エンドポイントは `https://api.xroute.ai/v1/messages`（ヘッダーに `x-api-key` と `anthropic-version: 2023-06-01`）です：

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://api.xroute.ai/v1/messages" \
      -H "x-api-key: $XROUTE_API_KEY" \
      -H "anthropic-version: 2023-06-01" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "Anthropic/claude-fable-5",
        "max_tokens": 1024,
        "messages": [
          {"role": "user", "content": "量子コンピューティングを3文で解説してください。"}
        ]
      }'
    ```

    ```python Python
    from anthropic import Anthropic

    client = Anthropic(
        base_url="https://api.xroute.ai/v1",
        api_key="your_xroute_api_key",
    )

    message = client.messages.create(
        model="Anthropic/claude-fable-5",
        max_tokens=1024,
        messages=[{"role": "user", "content": "量子コンピューティングを3文で解説してください。"}],
    )
    print(message.content[0].text)
    ```

    ```typescript TypeScript
    import Anthropic from '@anthropic-ai/sdk';

    const client = new Anthropic({
      baseURL: 'https://api.xroute.ai/v1',
      apiKey: process.env.XROUTE_API_KEY,
    });

    const message = await client.messages.create({
      model: 'Anthropic/claude-fable-5',
      max_tokens: 1024,
      messages: [{ role: 'user', content: '量子コンピューティングを3文で解説してください。' }],
    });
    console.log(message.content[0].text);
    ```
    </CodeGroup>
  </Tab>

  <Tab title="3. プロバイダーネイティブ形式">

### 1. OpenAI 画像生成 & 編集

<CodeGroup>
```bash 画像生成 cURL
curl -X POST "https://api.xroute.ai/OpenAI/images/generations" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \

    "prompt": "サイバーパンク調の雨の東京の夜景、ネオンサインの反射、高解像度 8k",
    "n": 1,
    "size": "1024x1024"
  }'
```

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="https://api.xroute.ai/OpenAI",
    api_key="your_xroute_api_key",
)

response = client.images.generate(
```

### 2. Google ネイティブ画像生成

```bash cURL
      {

          {"text": "A futuristic architectural pavilion surrounded by serene mist and pine trees"}

      }

    "generationConfig": {
      "responseModalities": ["IMAGE"]
    }

```

```python Python (google-genai SDK)
from google import genai

client = genai.Client(
    api_key="your_xroute_api_key",
    http_options={"base_url": "https://api.xroute.ai/Google"},
)

response = client.models.generate_content(
    model="gemini-3.1-flash-image",
    contents="A futuristic architectural pavilion surrounded by serene mist and pine trees",
    config={"response_modalities": ["IMAGE"]},
)
for part in response.candidates[0].content.parts:
    if part.inline_data:
        print("Received base64 image data")
```

## 動画出力モデルの呼び出し例

<Info>
**動画モデルはネイティブ非同期 2 段階モデルを採用しています**：最初に生成タスクを発行して `task_id` を取得し、次にポーリングで状態を確認して動画ダウンロード URL を取得します。
</Info>

### 1. Byteplus 動画生成タスク

- タスク発行：`POST https://api.xroute.ai/Byteplus/contents/generations/tasks`
- 状態照会：`GET https://api.xroute.ai/Byteplus/contents/generations/tasks/{task_id}`

<CodeGroup>
```bash 1. タスク発行
curl -X POST "https://api.xroute.ai/Byteplus/contents/generations/tasks" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-1-5-pro-251215",
    "content": [
      {
        "type": "text",
        "text": "青い海へ向かってゆっくりズームするドローン視点、波間から飛び跳ねるイルカ、4k"
      }
    ]
  }'
# レスポンス例：{"id": "cgt-2026xxxx-xxxx"}
```

```bash 2. 状態照会
curl -X GET "https://api.xroute.ai/Byteplus/contents/generations/tasks/cgt-2026xxxx-xxxx" \
  -H "Authorization: Bearer $XROUTE_API_KEY"
```

```python Python (Ark SDK 非同期動画生成)
import time
from byteplus_sdk_ark_runtime import Ark

client = Ark(
    base_url="https://api.xroute.ai/Byteplus",
    api_key="your_xroute_api_key",
)

# 1. タスク発行
create_result = client.content_generation.tasks.create(
    model="Byteplus/seedance-1-5-pro-251215",
    content=[{
        "type": "text",
        "text": "青い海へ向かってゆっくりズームするドローン視点、波間から飛び跳ねるイルカ、4k"
    }],
)
task_id = create_result.id
print(f"Task created: {task_id}")

# 2. 状態ポーリング
while True:
    task = client.content_generation.tasks.get(task_id=task_id)
    if task.status == "succeeded":
        print(f"Video URL: {task.content.video_url}")
        break
    elif task.status in ["failed", "cancelled"]:
        print(f"Task failed: {task.status}")
        break
    print("Generating video, waiting 5 seconds...")
    time.sleep(5)
```
</CodeGroup>

## インテリジェントルーティングとフェイルオーバー

XRoute は同等グレードのモデル間での自動リトライとフォールバックをサポートしています。上位プロバイダー側でレート制限 (429) や一時的な障害が発生した場合でも、ルーティング設定に従ってスムーズに代替モデルへ切り替え、サービスの可用性を維持します。

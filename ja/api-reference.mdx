XRoute は、統合された呼び出しプレフィックス **`https://api.xroute.ai`** の下で、60 以上の LLM、メディア生成モデル、および 100 以上のリアルタイムデータ API に対して統合 HTTP エンドポイントを提供します。

## ベース URL（呼び出しプレフィックス）

すべての API リクエストは共通のプレフィックス `https://api.xroute.ai` を使用します：

| 呼び出しモード / サービス | ベース URL / エンドポイント |
| :--- | :--- |
| **OpenAI 互換呼び出し** | `https://api.xroute.ai/v1` |
| **Anthropic 互換呼び出し** | `https://api.xroute.ai/v1/messages` |
| **ネイティブ形式呼び出し（Gemini ネイティブなど）** | `https://api.xroute.ai/v1beta` |
| **リアルタイムデータ・アカウント API** | `https://api.xroute.ai/apis/v1` |
| **MCP サーバー** | `https://mcp.xroute.ai/mcp` |

## 確定した呼び出しコスト

すべての有料レスポンスには、クレジット残高から差し引かれた正確な USD 金額を示す `x-xroute-cost-usd` ヘッダーが含まれます。

</Info>

リリース後は、単一のコマンドでコーディングエージェント（Claude Code、Codex、Cursor など）に XRoute API の検索、見積もり、呼び出し手順を組み込むことができるようになります。

## 公開までの間の接続方法

現時点でも、MCP または CLI を使用して AI エージェントを XRoute にすぐ接続できます。

<CardGroup cols={2}>
  <Card title="MCP で接続" icon="plug" href="/ja/agent-quickstart">
    ブラウザ OAuth を使用して、Claude Code、Codex、または Cursor に `https://mcp.xroute.ai/mcp` を追加します。
  </Card>

  <Card title="CLI を使用" icon="terminal" href="/ja/get-started/cli">
    ターミナルやスクリプトからモデルやデータ API の検索、見積もり、呼び出しを行います。
  </Card>
</CardGroup>

**XRoute モデルカタログ（Model Catalog）**へようこそ。XRoute は、世界の最先端モデルに対して統合クレジット課金、50ms 未満の超低遅延ルーティング、およびベンダーフェイルオーバーを提供します。

開発者が目的のモデルを**素早く見つけ**、スムーズに実装できるよう、また**SEO（検索エンジン最適化）**にも配慮し、本カタログは**出力モダリティ**と**プロトコル構造**ごとに整理されています：

## モダリティとプロトコル対応マトリクス

| 出力モダリティ | サポートする呼び出し形式 | コアエンドポイント | 主なユースケース |
| :--- | :--- | :--- | :--- |
| **テキスト生成 (Text)** | • OpenAI 統合形式 (`/v1/chat/completions`)<br />• Anthropic 統合形式 (`/v1/messages`)<br />• ネイティブ形式 (`/{Provider}/...`) | `https://api.xroute.ai/v1/chat/completions`<br />`https://api.xroute.ai/v1/messages`<br />`https://api.xroute.ai/{Provider}/...` | チャットボット、コーディングエージェント、構造化抽出、論理推論 |
| **画像生成 (Image)** | • **プロバイダーネイティブ形式のみ** | `https://api.xroute.ai/{Provider}/images/generations`<br />`https://api.xroute.ai/Google/image/...` | 広告ビジュアル、UI モックアップ、ゲームアセット、デザイン |
| **動画生成 (Video)** | • **ネイティブ非同期タスクのみ**（作成とポーリング） | 作成: `https://api.xroute.ai/{Provider}/.../tasks`<br />照会: `https://api.xroute.ai/{Provider}/.../tasks/{id}` | 短尺動画広告、キャラクターモーション、映像プリビズ |

## 統合認証とルーティング

すべてのモデルとモダリティのリクエストは、XRoute の**共通 API キー**を使用します：

```bash
export XROUTE_API_KEY="xr_live_your_key_here"
```

- ゲートウェイベース URL: `https://api.xroute.ai`
- 共通クレジット: 1 つの残高ですべてのベンダーモデルを利用可能。
- リアルタイムカタログ: 最新の料金とレイテンシは [xroute.ai/en/model](https://xroute.ai/en/model) をご覧ください。

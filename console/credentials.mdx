The **Access Credentials** page (`https://xroute.ai/personal/keys`) allows you to generate and manage secret API keys used by applications, backend services, and coding agents to authenticate against XRoute endpoints.

</Frame>

## Default Key

Upon account registration, XRoute automatically creates a primary credential named **`default`**:

- **Key Format**: Starts with `sk-` followed by an encrypted hexadecimal token.
- **Resource Scope**: By default, it dynamically inherits all resource permissions assigned to your account and joined resource groups.
- **Actions**:
  - Click the **Eye icon** to view the unmasked key or click **Copy** to copy the secret key to your clipboard.
  - View the creation timestamp and authorized resource groups.

---

## Creating New API Keys

To isolate credentials across distinct environments (e.g. Production vs. Staging) or different applications:

1. Click **Create** at the top right of the credentials card.
2. In the modal, provide a descriptive **Credential Name** (e.g. `claude-code-cli`, `cursor-ide`, `prod-backend`).
3. Set resource permission scope:
   - **Dynamic follow**: Automatically gains access to all models enabled for your account.
   - **Custom scope**: Bind this credential strictly to specific resource groups or models.
4. Click **Confirm** to generate the new API key.

<Warning>
Always treat your `sk-...` API keys as sensitive credentials. Never commit them to public version control repositories or expose them in client-side browser bundles.
</Warning>

The **Personal Dashboard** (`https://xroute.ai/personal/dashboard`) is the landing page of the XRoute Console, offering an immediate operational pulse of your AI gateway account.

<Frame caption="XRoute Personal Dashboard with live balance, quick call snippets, and recent invocations">
  <img src="/images/console/dashboard.png" alt="Personal Dashboard" />
</Frame>

## Key Metric Cards

At the top of the dashboard, four metric cards display your vital account stats:

- **Account Balance (USD)**: Shows your real-time available cash balance. Click **Details** to jump to your full balance statement or top up.
- **Today's Usage**: Shows the net settled dollar amount consumed today.
- **Today's Calls**: Shows the total number of API requests processed today, alongside a comparison with the same period yesterday. Click **Trend** to open historical charts.
- **Accessible Resources**: Shows the total count of AI models available to your account (e.g. `16 / 80` providers/LLMs). Click **View All Resources** to browse available models.

## Quick Call Guide

The **Quick Call Guide** enables developers to test models immediately without writing boilerplate code or manually piecing together tokens and headers:

<Steps>
  <Step title="Select Type & Resource">
    Choose **AI Model** under Type, then select your desired model from the dropdown (e.g., `Anthropic / Claude Fable 5`, `OpenAI / gpt-6-astra`, `DeepSeek / DeepSeek-V3`).
  </Step>

  <Step title="Select Identity & Credential">
    Select **Personal Account** and pick the target credential key (e.g., `default`).
  </Step>

  <Step title="Choose Protocol Format">
    Switch between three standardized invocation protocols:
    - **OpenAI Compatible Format**: Standard `https://api.xroute.ai/v1/chat/completions` endpoint compatible with standard OpenAI SDKs.
    - **Claude Compatible Format**: Standard `https://api.xroute.ai/v1/messages` endpoint compatible with Anthropic SDKs.
    - **Native Invocation Mode**: Direct provider-specific formats (including native image generation and async video tasks).
  </Step>

  <Step title="Copy and Execute">
    Select your preferred programming language (**CURL**, **Python**, or **TypeScript**), click **Copy Code**, and paste the command into your terminal to run immediately.
  </Step>
</Steps>

```bash Ready-to-run cURL generated by Quick Call Guide
curl -X POST 'https://api.xroute.ai/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: sk-*****************************3582' \
  -d '{"model": "Anthropic/claude-fable-5", "messages": [{"role": "user", "content": "Hello"}]}'
```

## Recent Calls

The bottom section of the Dashboard displays the **10 most recent resource invocations** with exhaustive technical and billing data:

| Field | Meaning |
| :--- | :--- |
| **Request Time** | Accurate timestamp (down to the second) of the request. |
| **Provider & Model** | Upstream supplier name and concrete model identifier used. |
| **Duration** | End-to-end gateway response latency. |
| **Status** | HTTP outcome status (e.g. `200 Success`, error codes). |
| **Consumer & Key** | Credential name (e.g. `default`) that authorized the invocation. |
| **Token Breakdown** | Precise breakdown of **INPUT**, **OUTPUT**, and **TOTAL** token counts. |
| **Billing Details** | Standard Price, Discounted Price, Billing Formula, Consumption Amount, Voucher Deduction, and Balance Deduction. |

Click **View All Call Statistics** in the top right of the table to open the full [Call Statistics](/console/call-statistics) report.

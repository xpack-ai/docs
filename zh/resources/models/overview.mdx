## 模态与调用协议支持矩阵

| 输出模态 | 支持的调用协议 | 核心接口端点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **文本生成 (Text)** | • OpenAI 统一格式 (`/v1/chat/completions`)<br />• Anthropic 统一格式 (`/v1/messages`)<br />• 原生格式直连 (`/{Provider}/...`) | `https://api.xroute.ai/v1/chat/completions`<br />`https://api.xroute.ai/v1/messages`<br />`https://api.xroute.ai/{Provider}/...` | 智能体对话、代码补全与审查、结构化数据提取、数学逻辑推理 |
| **图片生成 (Image)** | • **仅支持供应商原生格式** | `https://api.xroute.ai/{Provider}/images/generations`<br />`https://api.xroute.ai/Google/image/...` | 营销海报、插画生成、电商产品图、概念设计 |
| **视频生成 (Video)** | • **仅支持供应商原生异步任务**（创建任务 + 轮询状态） | 提交: `https://api.xroute.ai/{Provider}/.../tasks`<br />查询: `https://api.xroute.ai/{Provider}/.../tasks/{id}` | 影视分镜、广告创意短片、动态角色渲染 |

## 统一认证与路由配置

无论调用哪个供应商或何种生成类型，统一使用您的 **XRoute 通用 API 密钥**：

```bash
# 在环境中导出密钥
export XROUTE_API_KEY="xr_live_your_key_here"
```

- 网关基础地址：`https://api.xroute.ai`
- 通用积分：一个账户余额即可调用全平台全部模型。
- 在线实时列表：访问 [xroute.ai/en/model](https://xroute.ai/en/model) 查看最新模型单价与实时延迟数据。

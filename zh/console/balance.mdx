## 当前可用余额

页面顶部突出展示**当前账户余额（USD）**：

- 实时显示可用于大模型与 API 调用的可用现金资产。
- **立即充值**：点击按钮呼出安全支付窗口，支持主流支付通道在线充值。
- **核对旧系统余额**：若您曾使用过旧版 XRoute 系统，可在此一键核对并划转资产。

## 消费流水与充值记录

余额卡片下方提供两个核心账单标签页：

### 1. 每日消耗明细
按天汇总聚合消费数据：
- **结算日期**
- **调用总次数**
- **Token 消耗总量**
- **代金券抵扣额**
- **现金余额抵扣额**

### 2. 充值记录
提供不可篡改的充值财务账单凭证：
- **订单流水号**
- **充值金额（USD）**
- **支付渠道与方式**
- **下单时间与付款时间**
- **订单状态**（已支付、处理中、已退款等）

## 子资源消费排行（TOP 20）

为了帮助研发与财务团队快速识别成本核心，控制台自动汇总并排行指定周期内**消耗金额最高的 20 个子资源**：

| 列名 | 说明 |
| :--- | :--- |
| **排名** | 按消费金额从高到低排列（1 至 20）。 |
| **子资源名称** | 具体的模型名称与编号（如 `Anthropic/claude-fable-5`、`OpenAI/gpt-6-astra`）。 |
| **父资源名称** | 所属供应商或上级服务组。 |
| **资源类型** | 生成模态（`text` 文本、`image` 图像、`video` 视频）。 |
| **调用次数** | 该模型累计收到的调用总数。 |
| **最后调用时间** | 最近一次请求的发生时间。 |
| **消费金额（USD）** | 该资源产生的消费总金额。 |

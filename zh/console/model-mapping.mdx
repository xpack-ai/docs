**模型映射策略页面**（`https://xroute.ai/personal/model-mapping`）是 XRoute 提供的企业级高可用能力，让开发者无需修改客户端代码即可实现模型别名解耦与自动化容灾切换。

## 核心业务价值

- **客户端解耦**：代码中直接请求自定义抽象名称（如 `prod-fast-llm`）或通用标准名称（如 `gpt-4o`），后台动态映射到实际目标模型（如 `Anthropic/claude-fable-5`）。
- **零停机平滑升级**：当发布新模型或需要调整上游供应商时，直接在控制台修改映射目标，客户端无需重新打包发布。
- **自动化故障转移（Failover）**：当首选目标模型遇到供应商限流（429）、服务不可用（502/503）或延时突增时，XRoute 自动无缝降级重试至预设的备用容灾模型。

## 策略配置参数

点击**新建模型别名映射**按钮进行配置：

| 配置项 | 说明 |
| :--- | :--- |
| **映射新名称（实际请求值）** | 客户端在 API 请求中传递的 model 参数值（如 `company-llm-fast`）。 |
| **首选目标映射模型** | 正常情况下优先分发的真实目标大模型。 |
| **供应商参数模板** | 预置系统级参数（如默认 `temperature`、`max_tokens`、系统提示词注入等）。 |
| **模型类型** | 支持的生成模态（`text` 文本、`image` 图像、`video` 视频）。 |
| **灾备容灾规则** | 备用目标模型优先级队列（例如当主模型调用失败时，自动重试至次优模型）。 |
| **可用性与启用状态** | 一键开启或暂停该映射策略的即时生效。 |
| **更新时间** | 策略修改的版本审计时间戳。 |

**访问凭证管理页面**（`https://xroute.ai/personal/keys`）用于管理应用程序、后端服务及 AI 智能体接入 XRoute 网关所需的 API 密钥凭证。

## 默认访问密钥

注册账户后，XRoute 会自动为您初始化一个名为 **`default`** 的主密钥：

- **密钥格式**：以 `sk-` 开头，后接高强度加密的十六进制凭证串。
- **资源权限**：默认**动态跟随账户权限**，即自动拥有当前账户及所属资源组被授权的所有模型调用权限。
- **快捷操作**：
  - 点击眼睛图标可明文查看密钥，点击复制按钮可一键复制至剪贴板。
  - 查看创建时间及关联的资源组。

---

## 创建新的 API 密钥

若需要对生产环境、测试环境或不同业务项目进行密钥隔离：

1. 点击凭证卡片右上角的**新建**按钮。
2. 在弹出窗口中输入易于辨识的**凭据名称**（如 `claude-code-cli`、`cursor-ide`、`prod-backend`）。
3. 配置资源权限范围：
   - **动态跟随**：自动获得当前账户拥有的全部模型权限。
   - **自定义绑定**：仅限制该密钥可访问特定的资源组或模型。
4. 点击**确定**即可生成全新的 API 密钥。

<Warning>
`sk-...` 密钥属于机密凭据，请切勿将其提交到公共代码仓库或暴露在前端浏览器代码中。
</Warning>

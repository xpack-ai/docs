**代金券页面**（`https://xroute.ai/personal/credit`）用于管理您通过平台活动、开发者计划或专属渠道获得的代金券资产。

## 优先抵扣规则

在调用 XRoute 的大模型与 API 服务时：

<Tip>
**代金券始终优先于现金账户余额进行抵扣。**

当您的账户中存在符合调用范围且处于有效期内的代金券时，系统会自动优先使用代金券余额冲抵费用，直到代金券额度耗尽后才会扣除您的账户现金余额。
</Tip>

---

## 兑换代金券

若您获取到了官方发放的代金券码或体验礼券：

1. 在**代金券兑换**区域点击**兑换**按钮。
2. 在输入框中输入您的**代金券兑换码**。
3. 确认后，代金券面额将立即入账并激活。

## 代金券资产列表明细

资产表格完整记录每一张代金券的状态与可用情况：

| 列名 | 说明 |
| :--- | :--- |
| **代金券编号** | 平台内部唯一资产识别码。 |
| **代金券名称** | 活动或礼券名称（如新用户上手礼包、黑客松赞助金等）。 |
| **面值** | 兑换时的初始赠送总金额。 |
| **剩余余额** | 当前仍可用于抵扣调用的剩余金额。 |
| **适用范围** | 允许使用的模型范围（如全部模型可用、仅限文本模型、指定厂商等）。 |
| **兑换时间** | 兑换成功的具体时间戳。 |
| **有效期至** | 代金券过期截止日期，过期后未消耗额度自动作废。 |
| **状态** | 当前状态（有效、已用尽、已过期）。 |
| **操作** | 查看消费抵扣明细或使用规则说明。 |

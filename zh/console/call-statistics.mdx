## 时间与高级筛选

顶部提供灵活的数据范围控制：

- **快捷时间跨度**：**今天**、**昨天**、**近 7 天**、或**自定义时间**。
- **个人限频与配额**：快速查阅当前账户的 QPM（每分钟请求数）与并发调用配额。
- **高级筛选**：支持按特定**供应商**、**模型**、**状态码**（如 200、429、500 等）或**凭证 Key** 进行精确定位。

---

## 核心指标大盘卡片

五大核心指标提供宏观健康度概览：

- **调用总次数**：所选时间段内处理的全部 API 请求总数。
- **调用成功率**：返回 HTTP 200 状态的请求占比百分比。
- **平均耗时**：端到端网关及模型响应的平均耗时（以毫秒或秒为单位）。
- **调用总 Token 数量**：所产生的 Prompt 输入 Token 与 Completion 输出 Token 累计总和。
- **总消费金额**：对应周期内已结算的净费用总额（USD）。

## 模型调用趋势图

交互式折线与面积图展示随时间推移的业务流量形态：

- 直观对比不同厂商及模型之间的流量分布（如 Anthropic 与 OpenAI 或 DeepSeek 的调用占比）。

## 逐笔调用审计明细

页面底部完整记录每一笔 API 调用的技术与财务全生命周期流水：

| 字段 | 含义 |
| :--- | :--- |
| **请求时间** | 请求到达网关的精确时间。 |
| **供应商与模型** | 实际承接调用的底层厂商和模型编号。 |
| **耗时** | 包含上游处理与网络传输的完整耗时。 |
| **状态** | HTTP 状态码。 |
| **调用方与凭证** | 触发该调用的 API 密钥标识。 |
| **Token 明细** | 精确列出 **INPUT**、**OUTPUT** 与 **TOTAL** 数量。 |
| **计费与抵扣** | 适用的计费单价、折扣单价、代金券抵扣额与现金余额扣除额。 |

## v1.7

> **支持 Agent 读取和调用 & 代金券系统**

### Agent 调用支持、代金券体系与计费公式透明化

- **支持 Agent 读取与调用：** 全面优化面向 AI Agent 的资源读取、发现与接口调用体验。
- **推荐资源配置：** 系统后台与渠道后台“平台装修”新增推荐资源配置，支持按 **模型、API、MCP** 分别筛选已发布资源并自定义排序，前台列表页优先置顶展示前 8 项推荐资源。
- **全流程代金券系统：**
  - **代金券创建与管理：** 系统与渠道管理后台“财务管理”新增 **代金券管理**，支持自定义或随机生成 6–18 位大写字母与数字兑换码，灵活配置面额（从渠道余额预扣）、有效期（最长 1 年）、可兑换次数及适用范围（全站通用或指定模型/API 父子资源），支持随时关闭兑换码并查看已兑换明细与抵扣流水。
  - **个人兑换与独立兑换页：** 个人后台“账号余额”新增 **代金券** 菜单，同时上线前台独立活动兑换页（`/redeem` 及页脚入口）；同一资源命中多张代金券时按到期时间由近及远优先抵扣，余额不足部分自动衔接账户余额扣减。
- **消费金额算法与明细透明化：** 调用统计列表新增 **可见列自定义** 功能，并新增 **标准价、折后价、计费单位（`M token` / `call` / `s`）、计费公式（代入实际变量展示计算过程）、消费金额、代金券抵扣、余额扣减** 列，让每一笔调用的计费与抵扣逻辑一目了然。
- **自定义菜单路径与广告跳转优化：** 平台装修上传本地 HTML 自定义菜单时支持配置专属访问路径（`/pages/{custom_path}`）并实时校验唯一性；顶部广告横幅新增点击新窗口跳转 URL 配置。

## v1.6

> **支持交易和订阅并行**

### 交易与订阅并行模式、平台装修与消费者模型别名映射

- **交易计费与订阅审批并行：** 系统设置新增 **功能配置** 中心，打破原“订阅模式”与“计费模式”二选一限制，支持独立开关 **未授权资源可访问、支持订阅申请与审核、支持付费交易、支持分销渠道** 及启用的资源类型（AI 模型 / API 服务 / MCP），满足企业“先审批调用权限、再按额度计费管控”的混合治理诉求。
- **平台装修与多语言导航菜单：** 系统与渠道后台新增 **平台装修** 菜单，支持多语言（中/英等）顶部导航菜单自定义，菜单项可指向官方页面（首页、模型、API、MCP）、外部自定义链接或上传本地 HTML 页面，并集中管理首页主题文案与顶部广告位。
- **消费者模型别名映射与用户级灾备：** 个人后台与资源组详情新增 **模型别名映射**，支持将自定义模型名称映射至目标供应商模型，并可按优先级配置同类型备选灾备模型（故障时自动切换并按实际调用模型计费，优先级高于平台级供应商灾备）。
- **多样化充值方式：** 系统管理后台新增 **新用户注册自动赠送金额** 开关与 **批量充值** 功能（支持全选、按资源组或多选用户批量充值，并完整记录历史批量操作流水）。
- **通知公告中心升级：** 原“待办通知”升级为 **通知公告**，个人端新增系统通知（反馈分销申请审批结果及拒绝原因），渠道端新增系统通知（实时推送上游模型上下架及价格变更提醒）；同时全面消除未发布模型在可订阅列表中的透出及纯 ID 报错提示。

## v1.5

> **多模态在线调试 & 二级渠道前台优化**

### 多模态模型在线调试与二级渠道品牌深度定制

- **多模态在线调试（Playground）：**
  - 模型详情页新增 **在线体验** 标签页，支持切换不同请求 URL 格式，提供 **可视化动态表单** 与 **JSON 编辑器** 双向实时同步输入。
  - 支持 **文本（Text）、图像（Image）与视频（Video）** 多模态在线调试（视频模型支持创建异步生成任务与基于任务 ID 查询预览视频结果），提供多图/多视频缩略图切换及预览/原始 JSON 响应一键切换。
- **二级渠道前台全站动态品牌化：**
  - 全站动态适配渠道自定义 Logo、品牌名称、首页中央文案、模型列表（自动隐藏模型数为 0 的分类）及模型库标语（自动拼接当前站点名与最新上线模型）。
  - 常规设置新增 **顶部广告条配置**（支持自定义文案、字体颜色及渐变背景色调色盘）、多渠道 **联系方式配置**（X、联系邮箱等）以及下游渠道 **隐私政策与服务条款主体信息自动替换**。
- **渠道后台“快速开始”向导：** 渠道后台左侧导航新增 **快速开始** 菜单，提供四步初始化配置引导（定义品牌信息 → 调整上架资源可调用 → 设置分销价格策略 → 渠道余额充值），实时追踪完成状态并支持一键跳转配置。

## v1.4

> **供应商灾备、充值报表与消费报表**

### 供应商高可用灾备策略与账单统计体系

- **供应商灾备策略与多 Key 号池轮转：**
  - 系统后台策略管理新增 **供应商灾备**（支持版本管理与即时启用开关），可基于统一参数模板配置 **直接替换原供应商参数** 或 **条件触发灾备**（上游连接/鉴权/5XX/额度不足失败触发，或超过自定义响应超时秒数触发）。
  - 支持按顺序配置最多 10 个备选供应商、支持一键测试连通性，并允许配置同一端点不同 API Key 实现 **号池轮转**。
- **账单统计（消费报表与充值报表）：**
  - 财务管理新增 **账单统计**，包含 **消费报表** 与 **充值报表** 两大视图，支持按账号、资源组、渠道检索时段内的调用次数、最后调用时间、消费总额与充值总额。
  - 点击消费报表中的消费者可下钻查看其消耗排名前 20 的子资源（模型或 API）消费明细。
- **个人消费明细与账户账单穿透：** 个人后台“账号余额”每日消费记录下方新增 Top 20 子资源消费排名；系统后台与渠道后台“账号管理”支持直接点击账户余额弹窗查看该用户的每日消费汇总与充值订单记录。

## v1.3

> **Dashboard、Claude 格式统一与授权证书**

### 全角色数据仪表盘、Claude 格式统一接入与私有化授权证书

- **多角色数据仪表盘（Dashboard）：**
  - **个人仪表盘：** 集中展示账户余额与近 30 天每日消耗折线图、今日调用量（对比昨日同期）及近 7 天模型/API 调用对比条形图、当前可访问资源统计、快速调用配置与最新 10 条调用记录。
  - **渠道与管理后台 Dashboard：** 涵盖渠道品牌与域名卡片、本月销售额与利润环比、近 7 天活跃用户趋势、分销渠道网络概览、资源盘点（今日 API 调用 Top 3、今日模型 Token 消耗 Top 3）、组织盘点以及本月充值/消费 Top 5 排行榜；管理后台支持右上角切换查看不同渠道视角数据。
- **Claude 格式统一接入：** 统一支持 Anthropic Claude 标准格式调用，与 OpenAI 兼容格式及上游原生格式共同构成三大标准调用模式。
- **私有化授权证书管理：** 系统设置新增 **授权证书（License）** 菜单，展示授权公司、部署节点数上限、允许分销层级（0–5 级）及有效期，并提供 **授权过期、节点数超额、分销层级超额** 三类异常横幅预警。

## v1.2

> **统计报表与策略管理**

### 限流/限额策略、全维度 Token 统计与销售报表

- **限流策略与限额策略：**
  - **限流策略（Rate Limit）：** 支持按分钟、小时、自然日、自然月、自然年及总额周期限制调用次数，可针对个人账号、资源组自身凭证、资源组成员凭证或整个渠道生效，并支持进入二级页面查看各命中对象的额度消耗进度。
  - **限额策略（Quota Limit）：** 支持按 **百万 Token** 或 **美元金额（USD）** 设置消费配额上限（支持按日、月、年自动重置或总额限制），并在个人/资源组/渠道调用统计中展示已命中的限额策略清单。
- **调用统计总览看板：** 调用统计新增 **总览** 标签页，展示时段内总调用次数（含日均调用）、平均响应时间（ms）、平均成功率、峰值调用频率（RPM）以及 Top 5 模型、API 服务、资源组与账号排行。
- **多维 Token 统计中心：** 新增 **Token 统计** 菜单，涵盖 **总览、账号、资源组、下游渠道、模型** 五大维度，展示累计消耗 Token（拆分 Input / Output Token）、峰值 TPM、平均单次调用消耗与平均消费者消耗，支持下钻查看消费者调用的模型分布或模型对应的消费者明细。
- **销售报表与下游业绩穿透：** 财务管理新增 **销售报表**，统计销售总额、净利润、本渠道直销额与下游分销额趋势，提供 Top 20 资源销售明细与每日销售明细并支持导出完整 Excel 报表；支持从下游渠道列表或分销分润页一键穿透查看下游渠道销售报表。

## v1.1

> **交易体系与多级分销**

### 计费交易体系、多级渠道分销与动态定价引擎

- **渠道与资源组体系升级：** 原“租户”升级为 **渠道（Channel）**，原“团队”升级为 **资源组（Resource Group）**，全面构建支持多级分销的交易架构。
- **多级分销渠道管理：** 个人后台支持提交 **分销申请**，上级渠道审批通过并关联权限资源组后即可开通下游渠道后台；支持分配渠道管理员、查看下游渠道客户数与当月业绩、一键封禁/解封下游渠道，以及配置渠道专属品牌名、Logo、二级域名或独立域名。
- **模型与 API 服务精细化定价：**
  - **模型定价：** 支持按 Token（Input / Output）、按次（Per Call）、按秒（Per Second）及 **高级分层计费（Advanced Billing，支持缓存 Token、多模态输入、不同分辨率视频按秒计价等）**；提供 **官方价（划线价）、进货价、售价** 三套视图，支持按比例配置 **动态调价策略** 与兜底策略，并内置防亏本保护（售价或折扣价低于进货价时自动对齐进货价）。
  - **API 服务定价：** 支持按单次调用（Per Call）设置统一兜底售价、标价及针对特定接口的差异化价格策略，前台自动展示折扣标识、划线原价与详细计费规则表。
- **资源组折扣策略：** 策略管理新增版本化 **折扣策略**，支持面向不同资源组按供应商/模型或 API 服务/接口批量配置专属折扣比例。
- **账户充值、渠道拨款与分销分润结算：**
  - 支持个人账户与渠道账户美元余额管理（保留 6 位小数）、Stripe 线上充值、渠道管理员向下游用户线下拨款及系统后台充扣操作。
  - 财务管理新增 **分销分润**，支持配置提现门槛（默认 $100）与手续费率（默认 2%）、绑定收款银行账户、按结算周期发起利润提现，以及上级渠道对下级提现申请的审批、消费明细核对与打款确认。
- **模型与 API 调用统计：** 新增模型与 API 服务调用统计看板及调用日志列表，详细记录输入/输出 Token、扩展计费参数、客户端 IP、请求/响应报文及单次消费金额，并强化 API Key 创建查重与防遍历安全机制。

## v1.0

> **界面框架和逻辑调整**

### AI 资源开放平台全新架构：统一整合 Model、API 与 MCP

- **三大 AI 资源统一门户：** 全新升级前台首页与导航框架，统一承载 **AI 大模型（Model）、API 接口（API）、MCP 服务（MCP）** 三大核心资源分类检索与统一调用指引，支持在系统后台自定义站点品牌名称、Logo 与首页标语。
- **统一调用与原生调用双模式：**
  - **Model 详情页：** 新增 **统一调用模式**（OpenAI 兼容接口）与 **原生调用模式**（透传上游原生路径及二级调用路径如 `text_to_video`、`image_to_video`），支持选择接入团队与密钥后自动填充至多语言示例代码并一键复制。
  - **API / MCP 详情页：** 统一展示服务概览（Overview）、接口列表（API）与 MCP 工具集（MCP Tools），右侧提供接口在线调试模式与多语言请求示例（cURL、Python、Java、PHP 等）密钥自动替换与一键复制。
- **权限架构重构（去除消费者冗余层级）：** 将原“团队 → 消费者 → 访问鉴权”三级结构简化为 **“团队（资源组）→ 访问鉴权”** 两级结构；密钥默认开启 **动态跟随团队/账号资源权限**，也可关闭跟随并精细化指定单个密钥可访问的 API 服务与大模型范围。
- **资源版本发布与即时调用开关：** API 服务与模型供应商均支持版本化发布管理及首次发布检查清单；新增供应商与模型级 **调用状态即时开关**，无需重新发版即可实时控制前台可见性与可调用性。
- **统一待办通知与团队协作：** 新增统一 **待办通知** 中心集中审批所有 API 与模型订阅授权申请；支持团队成员角色划分（所有者、管理员、普通成员）、邀请链接一键加入，以及新注册账号默认分配资源组与角色逻辑配置。

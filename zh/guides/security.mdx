XRoute 构建于企业级 AI 网关架构之上，专为严格的数据隐私和可预期的智能体治理而设计。

## 数据处理

XRoute 充当高速路由与结算层。您的请求经过身份认证后，会被路由至最健康的上游集群，并直接返回给您的客户端。

## 提示词与输出留存

- **零数据训练：** XRoute 绝不会使用您的提示词、补全结果或数据 API 负载来训练模型。
- **默认不记录内容日志：** 除非您在控制台工作空间中显式开启调试追踪，否则提示词正文和模型响应不会持久化存储在 XRoute 数据库中。

## 运行元数据

为支持计费、速率限制和审计日志，XRoute 仅记录最少的请求元数据：

- 时间戳与请求 ID
- API 密钥 ID 与组织 ID
- 目标模型或端点 ID
- Token 数量（输入/输出）与结算的美元费用
- HTTP 状态码与延迟

## 身份认证与传输安全

- 所有流量均要求使用 **TLS 1.2+**（`https://api.xroute.ai` 与 `https://mcp.xroute.ai`）。
- API 密钥均以加盐加密哈希的形式存储。

## 智能体安全控制

在授予自主智能体访问 XRoute 的权限时：

1. 使用 **OAuth MCP 登录**，避免在纯文本文件中共享原始 API 密钥。
2. 在控制台中设置**单密钥消费上限**。
3. 在执行写操作或超出自动执行报价阈值的调用前，要求用户确认。

按照以下步骤创建您的 XRoute API 密钥，调用前沿大语言模型与多模态生成 API，并核对您的用量。

<Tip>
本指南已整合并移入**快速上手 · 面向开发者**目录下的统一教程：[快速上手：获取 API Key 与首次调用](/zh/quickstart)。
</Tip>

## 1. 登录控制台并获取 API 密钥

1. 登录 [xroute.ai/en](https://xroute.ai/en) 并充值通用积分（Credits）。
2. 点击首页横幅的 **Get API Access** 或导航栏右上角的个人头像进入控制台。
3. 在左侧菜单中进入 **Access Credentials（访问凭证）**（`https://xroute.ai/personal/keys`）。
4. 在凭证列表中选择 `default` 密钥，点击 API Key 输入框右侧的 **复制** 图标直接复制密钥（`sk-...`）。

<Frame caption="XRoute Access Credentials 控制台界面与 API Key 复制">
  <img src="/images/quickstart/api-keys-overview.png" alt="XRoute 访问凭证控制台" />
</Frame>

5. （可选）如果需要为不同业务系统分配独立凭证，点击凭证列表顶部的 **+ Create（新建）** 按钮创建并保存新密钥。

<Frame caption="新建访问凭证弹窗配置">
  <img src="/images/quickstart/create-api-key-modal.png" alt="新建访问凭证弹窗" />
</Frame>

6. 在您的终端环境中导出该密钥：

```bash
export XROUTE_API_KEY="sk_your_key_here"
```

<Warning>
切勿将 `$XROUTE_API_KEY` 提交到公开 Git 仓库或打印在不受信任的日志中。
</Warning>

## 2. 发起首次模型调用

XRoute 支持文本、图片与视频等多种生成类型。请根据输出类型选择正确的端点与协议：

<Note>
- **文本模型（Text）**：支持 **OpenAI 统一格式**、**Anthropic 统一格式** 及 **供应商原生格式**。
- **图片模型（Image）**：**仅支持供应商原生格式**（如 OpenAI Images API 或 Byteplus Images API）。
- **视频模型（Video）**：**仅支持供应商原生异步任务格式**（提交任务生成并轮询查询状态）。
</Note>

<Tip>
**极速调用方式**：您还可以在个人控制台的 **Dashboard**（`https://xroute.ai/personal/dashboard`）中使用 **Quick Call Guide（快速调用指引）**，选择任意模型和凭证后直接点击 **Copy Code** 复制包含完整 API Key 的 cURL 命令，粘贴到终端即可立即测试。
</Tip>

### A. 文本生成（OpenAI 统一格式）

向 `https://api.xroute.ai/v1/chat/completions` 发送请求：

```bash
curl -X POST "https://api.xroute.ai/v1/chat/completions" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "OpenAI/gpt-5.6-sol",
    "messages": [
      {"role": "system", "content": "You are a concise technical assistant."},
      {"role": "user", "content": "Explain low-latency edge routing in 3 bullet points."}
    ]
  }'
```

### B. 文本生成（Anthropic 统一格式）

向 `https://api.xroute.ai/v1/messages` 发送请求：

```bash
curl -X POST "https://api.xroute.ai/v1/messages" \
  -H "x-api-key: $XROUTE_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Anthropic/claude-fable-5",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "What makes a reliable API gateway?"}
    ]
  }'
```

### C. 图片生成（原生格式）

图片生成不支持聊天补全端点，直接调用供应商原生图片接口（例如 OpenAI 格式）：

```bash
curl -X POST "https://api.xroute.ai/OpenAI/images/generations" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "An ultra-modern data center glowing in cyberpunk neon lights, 8k resolution",
    "size": "1024x1024"
  }'
```

### D. 视频生成（原生异步任务）

视频生成采用异步工作流：先提交生成任务，再轮询任务状态（例如 Byteplus）：

```bash
# 1. 提交视频生成任务
curl -X POST "https://api.xroute.ai/Byteplus/contents/generations/tasks" \
  -H "Authorization: Bearer $XROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-1-5-pro-251215",
    "content": [
      {"type": "text", "text": "A drone flying through a sunset canyon, cinematic lighting"}
    ]
  }'

# 2. 根据返回的 task id 查询结果
# curl -X GET "https://api.xroute.ai/Byteplus/contents/generations/tasks/{task_id}" \
#   -H "Authorization: Bearer $XROUTE_API_KEY"
```

## 3. 查看消费情况与监控调用统计

您可以在 Web 控制台直观追踪用量、剩余余额与模型调用明细：

- **Dashboard**：访问 [Personal Dashboard](https://xroute.ai/personal/dashboard)，实时查看 **Account Balance（账户余额）** 与 **Today's Usage（当天使用金额）**。
- **Call Statistics**：在左侧 **REPORTS** 分组中访问 [Call Statistics](https://xroute.ai/personal/call)，查看 **Total Calls（总调用数）**、**Success Call Rate（成功率）**、**Average Duration（平均耗时）**、**Total Tokens Called（消耗 Token 总量）**、**Total Consumption Amount（总消费金额）** 以及各模型的 **Model Invocation Trend（调用趋势折线图）**。

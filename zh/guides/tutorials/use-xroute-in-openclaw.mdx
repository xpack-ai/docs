OpenClaw 智能体可以将 XRoute 同时用作 MCP 工具网关和主多模型 LLM 路由器。

## 1. 连接 XRoute 能力

### 步骤 1：添加服务器

将 `https://mcp.xroute.ai/mcp` 添加到您的 OpenClaw MCP 配置中。

### 步骤 2：登录

在 OpenClaw 提示时完成浏览器 OAuth 流程。

### 步骤 3：验证并重新加载

运行免费的 `account` 检查以验证您的 Credits 余额。

## 2. 可选：使用 XRoute 作为 LLM 提供商

### 步骤 1：获取您的 XRoute API 密钥

在 [XRoute 控制台](https://xroute.ai) 中生成一个密钥。

### 步骤 2：配置您的 API 密钥

```yaml
provider:
  name: openai-compatible
  base_url: https://api.xroute.ai/v1
  api_key: ${XROUTE_API_KEY}
  default_model: anthropic/claude-sonnet-4
```

让 Codex CLI 能够访问 XRoute 的 100+ 数据 API 与 60+ 模型。

## 前提条件

- 已安装 Node.js 18+ 和 Codex CLI。
- 一个 [XRoute](https://xroute.ai) 账户。

## 1. 安装 Codex

```bash
npm install -g @openai/codex
```

## 2. 添加 XRoute MCP 服务器

```bash
codex mcp add xroute --url https://mcp.xroute.ai/mcp
```

## 3. 验证连接

启动 `codex` 并让它运行免费的 `account` 操作以确认您的账户余额。

## 可选：基于 XRoute 模型运行 Codex

您也可以将 Codex 的核心模型推理请求路由至 XRoute：

```bash
export OPENAI_BASE_URL="https://api.xroute.ai/v1"
export OPENAI_API_KEY="$XROUTE_API_KEY"
codex --model openai/gpt-4.1
```

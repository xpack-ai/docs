配置 Cursor 将 XRoute 作为模型网关，直接调用全球主流大模型。

## 1. 在 Cursor 中配置 XRoute 模型（推荐）

打开 **Cursor Settings -> Models**：

1. 开启 **Override OpenAI Base URL** 并填写：
   ```text
   https://api.xroute.ai/v1
   ```
2. 将您的 `XROUTE_API_KEY` 粘贴到 OpenAI API Key 输入框中。
3. 添加需要调用的模型代号，例如：
   - `OpenAI/gpt-5.6-sol`
   - `Deepseek/deepseek-v4-flash`
   - `Anthropic/claude-fable-5`
   - `Google/gemini-3.1-pro-preview`

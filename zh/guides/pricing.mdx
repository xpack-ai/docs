XRoute 在全部 60+ 款大语言模型、视频/音频生成模型以及 100+ 项实时数据 API 中使用统一的预付费积分（Credits）余额。

## 积分与充值

- **1 Credit = $1.00 USD。**
- 在 XRoute 控制台中通过信用卡、支付宝、微信支付或加密货币为您的余额充值。
- 积分可在文本模型、推理模型、视频生成（如 Seedance 2.5）、音频合成及数据 API 中通用。

## 模型计费

- **文本与推理模型：** 按每百万输入 Token 和每百万输出 Token 计费。依托与 50+ 家上游提供商的合作关系，XRoute 提供低于官方直连的价格。
- **视频与音频模型：** 按生成的秒数、分辨率档位或请求单元计费。

## 数据 API 计费

- **按次固定计费：** 大多数搜索、金融和社交查询端点按每次成功调用收取固定的美元金额。
- **按量计费：** 批量提取或多记录端点在可预期的基础费用之上，按返回的记录条数计费。

## 费用预估、询价与扣费

发现与询价操作始终**免费**：

- `GET /v1/models`
- MCP 操作：`account`、`list_categories`、`search`、`get_details`、`batch_quote`
- CLI 命令：`xroute account`、`xroute search`、`xroute details`、`xroute quote --json`

## 先询价、再审核、后执行

在智能体工作流中运行付费调用之前，请先请求报价：

```bash
xroute quote search/web --json
```

如果报价返回 `"auto_execute_eligible": true`，说明此次调用在您预先批准的阈值范围内，可立即执行。否则，智能体会展示计划的调用、单价和总美元预算供您审批。

## 智能体工作流预算管理

将控制台中的**单密钥消费限额**与**调用前询价**（`batch_quote`）结合使用，确保自主运行循环绝不会超出您的预期预算。

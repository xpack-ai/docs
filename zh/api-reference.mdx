XRoute 在统一调用前缀 **`https://api.xroute.ai`** 下，为 60+ 大语言模型、媒体生成模型以及 100+ 实时数据 API 提供统一的 HTTP 端点。

## 调用前缀（Base URL）

所有 API 请求均使用统一的域名前缀 `https://api.xroute.ai`：

| 调用模式 / 服务 | 调用前缀 / 端点 |
| :--- | :--- |
| **OpenAI 兼容调用** | `https://api.xroute.ai/v1` |
| **Anthropic 兼容调用** | `https://api.xroute.ai/v1/messages` |
| **原生格式调用（如 Gemini 原生）** | `https://api.xroute.ai/v1beta` |
| **实时数据与账户 API** | `https://api.xroute.ai/apis/v1` |
| **MCP 服务器** | `https://mcp.xroute.ai/mcp` |

## 结算调用费用

每个付费响应均包含 `x-xroute-cost-usd` 响应头，用于报告从您的 Credits 余额中扣除的精确美元金额。

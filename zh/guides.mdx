XRoute 为 AI Agent 和开发者提供统一的网关入口，用于发现、调用和支付各类文本、图片与视频模型。

无需再为每个供应商单独注册账号和管理订阅，只需一个 API Key 即可访问：

- **主流大模型与多模态模型：** 支持通过 OpenAI 格式、Anthropic 格式或原生格式调用 OpenAI、Anthropic、Gemini、Grok、DeepSeek、Byteplus Ark、Qwen、Kimi、GLM、MiniMax 等模型。
- **图片与视频生成模型：** 原生调用 OpenAI DALL-E、火山方舟 Seedream、Google Imagen、Seedance 视频以及阿里 WAN 视频生成模型。
- **按量计费（Pay-per-use）：** 所有调用共用一个预充值余额，支持单 Key 消费限额与透明精确的用量统计。

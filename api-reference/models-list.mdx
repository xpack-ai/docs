## Endpoint

`GET https://api.xroute.ai/v1/models`

This endpoint is **free** and returns the live catalog of 60+ text, reasoning, image, video, and audio models.

```bash
curl https://api.xroute.ai/v1/models \
  -H "Authorization: Bearer $XROUTE_API_KEY"
```

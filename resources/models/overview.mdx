## Unified Authorization & Routing

Regardless of which model or modality you choose, all requests through XRoute use your **universal API key**:

```bash
# Export your unified API key
export XROUTE_API_KEY="xr_live_your_key_here"
```

- Universal Gateway Base URL: `https://api.xroute.ai`
- Consolidated Billing: One credit pool covers all vendors.
- Live Real-Time Catalog: Visit [xroute.ai/en/model](https://xroute.ai/en/model) for real-time model pricing and latency statistics.

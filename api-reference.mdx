XRoute provides unified HTTP endpoints under the base prefix **`https://api.xroute.ai`** for 60+ LLMs, media generators, and 100+ real-time data APIs.

## Base URLs

All API requests share the unified origin `https://api.xroute.ai`:

| Mode / Service | Base URL / Endpoint Prefix |
| :--- | :--- |
| **OpenAI-compatible Gateway** | `https://api.xroute.ai/v1` |
| **Anthropic-compatible Gateway** | `https://api.xroute.ai/v1/messages` |
| **Native Format Gateway (e.g., Gemini)** | `https://api.xroute.ai/v1beta` |
| **Real-time Data & Account APIs** | `https://api.xroute.ai/apis/v1` |
| **MCP Server** | `https://mcp.xroute.ai/mcp` |

Every paid response includes the `x-xroute-cost-usd` header reporting the exact USD amount deducted from your Credits balance.

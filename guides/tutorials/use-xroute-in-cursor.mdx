Configure Cursor to use XRoute as your LLM gateway to access frontier models across providers.

## 1. Configure XRoute models in Cursor (Recommended)

In **Cursor Settings -> Models**:

1. Enable **Override OpenAI Base URL** and set it to:
   ```text
   https://api.xroute.ai/v1
   ```
2. Paste your `XROUTE_API_KEY` into the OpenAI API Key field.
3. Add the model identifiers you wish to use, for example:
   - `OpenAI/gpt-5.6-sol`
   - `Deepseek/deepseek-v4-flash`
   - `Anthropic/claude-fable-5`
   - `Google/gemini-3.1-pro-preview`
